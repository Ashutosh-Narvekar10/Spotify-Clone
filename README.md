# Spotify Clone
A modern and responsive Spotify Clone built using HTML, CSS, and JavaScript.
This project recreates the core UI and music player experience of Spotify with custom animations, dynamic song handling, interactive controls, and stylish glassmorphism-inspired design elements.

<h3>-- Features...</h3>
- Play / Pause Music.<br>
- Next & Previous Song Controls.<br>
- Dynamic Song Information Update.<br>
- Dynamic Animated Gradient Theme Per Song.<br>
- Music Visualizer Animation.<br>
- Real-Time Song Duration & Progress Bar.
<br>

<h3>-- Fucntionalities...</h3>
- Songs play dynamically using JavaScript Audio API.<br>
- Auto next song feature when current song ends.<br>
- Dynamic footer color changes based on song.<br>
- Animated gradients for immersive visuals.<br>
- Music visualizer animation.<br>
- Smooth transitions throughout the UI.<br>
